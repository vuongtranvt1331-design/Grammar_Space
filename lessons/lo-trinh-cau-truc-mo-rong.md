# Lộ trình bổ sung: Các cấu trúc ngữ pháp chuyên đề

Giữ nguyên mã và số bài hiện có để bảo toàn tiến độ. Các chuyên đề bên dưới đã được tích hợp; các bài ôn tập liên quan đã được bổ sung câu hỏi phù hợp, giữ 100 câu Practice và 50 câu Apply.

## Từ loại và mức độ
- Enough / Too: đủ và quá mức — đã thêm Bài 49, nên học sau Bài 03 (Tính từ & Trạng từ).
- So / Such; So … that / Such … that — đã thêm Bài 50.
- There is / There are — đã thêm Bài 52.
- It takes / Spend — đã thêm Bài 54.

## Dạng động từ và sở thích
- Prefer / Would rather — đã thêm Bài 55.
- Used to / Be used to / Get used to — đã thêm Bài 51.
- Would rather + mệnh đề (hiện tại và quá khứ) — đã thêm Bài 55.
- Suggest + V-ing / that-clause — đã thêm Bài 58.
- Prevent / Stop + someone + from + V-ing — đã thêm Bài 58.
- Make / Let / Allow + tân ngữ + động từ — đã thêm Bài 58.
- Help + tân ngữ + động từ — đã thêm Bài 58.

## Động từ khuyết thiếu
- Had better so với Would rather — đã thêm Bài 55.

## Mệnh đề, câu hỏi và liên từ
- Câu hỏi đuôi — đã thêm Bài 59.
- Câu hỏi gián tiếp — đã thêm Bài 60.
- Because / Because of — đã thêm trong Bài 53.
- Although / Despite / In spite of — đã thêm trong Bài 53.
- Mục đích: to / in order to / so as to / so that — đã thêm Bài 57.
- Kết quả: so … that / such … that / as a result — đã hoàn thiện Bài 50.
- Both … and / Either … or / Neither … nor — đã thêm Bài 56.
- Not only … but also — đã thêm Bài 56.
- Unless / As long as / Provided that — đã thêm Bài 61.
- Mệnh đề danh từ — đã thêm Bài 60.
- Phân biệt liên từ và giới từ: because / because of, although / despite, during / while — đã thêm Bài 63.
- Liên từ tương quan và hòa hợp chủ ngữ – động từ — đã thêm Bài 56.

## Nâng cao
- It is time / It’s high time — đã thêm Bài 61.
- No sooner / Hardly / Scarcely và đảo ngữ — đã thêm Bài 62.
- Only after / Only when và đảo ngữ — đã thêm Bài 62.
- Not until và đảo ngữ — đã thêm Bài 62.
- As if / As though — đã thêm Bài 61.
- Do / does / did nhấn mạnh — đã thêm Bài 62.
- Mở rộng câu chẻ It is … that trong Bài 47 — đã bổ sung lý thuyết.
- Mở rộng giả định thức trong Bài 45 — đã bổ sung lý thuyết.
